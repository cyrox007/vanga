# 🎬 КиноВанга XD — нейросеть-кинокритик

> "Почему 'Крестный отец' получил 9.2? А 'Титаник' — 7.8?"
> **КиноВанга** предсказывает рейтинг фильма до его выхода.

## 📌 Описание

Модель анализирует:
- Год выхода и длительность
- Жанры (one-hot encoding)
- Режиссёра (средний рейтинг его прошлых работ)
- До 5 актёров (средний рейтинг их прошлых работ)
- Количество голосов (логарифм)

## 📊 Архитектура модели

### Признаки:
- **Жанры**: one-hot encoding всех жанров из IMDB
- **Год выхода**: нормализованный `(year - 1900) / 100`
- **Длительность**: нормализованная `runtime / 100`
- **Количество голосов**: `log1p(num_votes)`
- **Рейтинг режиссёра**: средний рейтинг всех фильмов режиссёра
- **Рейтинги актёров**: средние рейтинги до 5 актёров

### Алгоритм:
- SGDRegressor с функцией потерь Huber (устойчива к выбросам)
- L2 регуляризация
- StandardScaler для стандартизации признаков

## 🎯 Примеры предсказаний

После обучения модель будет учитывать:
- Драмы и документальные фильмы получают +0.1..+0.2 к рейтингу
- Хорроры получают -0.04 к рейтингу
- Известные режиссёры добавляют +0.12 к рейтингу
- Известные актёры добавляют +0.2..+0.4 к рейтингу
- Более новые фильмы имеют небольшой бонус

## ⚠️ Ограничения

- Модель работает только с фильмами (не сериалы)
- Для новых режиссёров/актёров используется средний рейтинг (~6.5)
- Предсказание ограничено диапазоном 0-10
